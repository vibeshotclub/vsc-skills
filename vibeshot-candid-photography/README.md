# Vibeshot Candid Photography

用于生成具有真实生活摄影感、偶然抓拍感、非常规摄影机位和强烈空间层次的人像写真提示词。

默认主体为：

> 一个极具镜头感的韩国 INS 网红，皮肤白皙，傲人身材。

除非用户主动修改主体，否则每组提示词都会保持这一人物设定。

## 能做什么

- 默认一次生成 10 组可以直接用于生图的完整中文提示词
- 随机组合表情、服装风格、场景、动作、景别、焦段、机位、构图、前景、光线和色彩
- 支持锁定任意条件，其余维度继续随机
- 主动拉开同批提示词之间的差异
- 强调自然抓拍、空间遮挡、非常规机位和真实摄影质感
- 避免影楼感、标准网红摆拍、塑料皮肤和 AI 假人感

## 安装

将本目录复制到 Codex Skills 目录：

```bash
mkdir -p ~/.codex/skills
cp -R vibeshot-candid-photography ~/.codex/skills/
```

安装后，在新的 Codex 对话中通过 `$vibeshot-candid-photography` 调用。

## 基本调用

```text
使用 $vibeshot-candid-photography，生成 10 组。
```

不指定数量时，默认输出 10 组。你也可以直接指定数量、画幅、场景、服装风格、焦段、机位、动作或其他要求。

## 常用输入模板

### 自由随机

```text
使用 $vibeshot-candid-photography，生成 {数量} 组。
```

### 锁定部分变量

```text
使用 $vibeshot-candid-photography，生成 {数量} 组，固定 {场景}、{服装风格}、{焦段}、{机位}，其余随机。
```

### 指定画幅与倾向

```text
使用 $vibeshot-candid-photography，生成 {数量} 组，画幅 {比例}，以 {低机位/高机位/长焦/广角} 为主，增加 {动态瞬间/室内场景/水边场景} 的比例。
```

### 修改主体

```text
使用 $vibeshot-candid-photography，生成 {数量} 组。主体改为 {人物描述}，其余条件随机。
```

### 只输出提示词

```text
使用 $vibeshot-candid-photography，生成 {数量} 组，只给提示词。
```

## 输出规则

- 每组都是一段可直接复制使用的自然语言提示词
- 默认使用 `### 01`、`### 02` 的编号格式
- 不输出变量解析、组合过程或摄影分析
- 用户指定条件的优先级最高，不会被随机变量替换
- 同一批次会尽量避免场景、动作、景别、焦段、机位、构图、前景和光线重复

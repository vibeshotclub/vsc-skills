# SUMMER BOYFRIEND POV

## 目标与输出

默认每次执行 **ONE STANDALONE PHOTOGRAPH**：一张独立照片、一幅画面、一个连续空间、一个连续瞬间。单图不等于单人，支持单人、双人和合理数量的多人同框。

以 Boyfriend / Partner / Friend / Companion POV 记录熟悉的人一起过夏天的自然瞬间，呈现私人相册、真实旅行和亲密陪伴感。保留用户指定的人数、身份、角色、参考职责、场景和比例；只为未指定的条件选择合适内容。

- 默认主体为一位 21–30 岁成年女性；用户指定其他成年人物或组合时按用户要求。
- 全部相关泳装人物明确为 21–30 岁成年人，具有成年外貌和身体比例。角色原作年龄较小、不明或幼态时，采用成年 COSER 的角色重新演绎，保留视觉 DNA，去除儿童比例和未成年学生感。
- 默认现实世界夏季旅行场景、真实摄影、无文字；COS 默认为 Level 2｜Recognizable Real-Life COS。
- 用户请求生成图片且有可用图像工具时，调用工具生成这一张照片；参考图作为生成条件传入，最终交付图片。
- 用户只要提示词时，输出一段可直接使用的完整摄影提示词；无图像工具时明确说明限制并提供该提示词，不声称已经生成图片。

## 执行流程

执行前读取 [完整创作规则](references/creative-direction.md)。它保留人物、参考图、COS、摄影和成像的全部创作细节；下列步骤用于组织一次执行。

1. 确定人物数量、成年身份、人物来源、角色与 COS 强度，锁定用户已明确的条件。
2. 检查用户提供的参考图，分别指定身份、发型、妆容、服装、配件、姿势、构图、机位、场景、光线、色彩或摄影风格职责。身份或角色对应关系不清且会影响结果时，简短询问；不要猜测交换人物。
3. 为每位人物建立独立的 Identity Anchor 和可选 Character Anchor：人物 A → 参考 A → 角色 A，人物 B → 参考 B → 角色 B。身份由人物参考决定；角色造型与人格由指定角色决定；泳装按角色重新设计。
4. 选定一个地点和一个正在发生的核心事件。多人围绕同一事件产生自然反应，例如 A 泼水、B 躲水、C 在旁笑。每个人具有合理位置、视线和肢体关系。
5. 选择一种主要摄影媒介、焦段、距离、机位和自然光，加入符合事件的水元素、真实皮肤、湿发、少量生活痕迹和摄影瑕疵。
6. 将条件写成自然摄影语言，明确全部人物成年、彼此独立、同一空间与同一瞬间，包含单图约束；生成前检查下方要求。

## 参考图职责

参考图只约束用户指定的维度，不无条件复制整个原画面。多幅参考是输入条件，不能作为照片嵌入输出画面。

| 参考职责 | 保留内容 | 新画面处理 |
| --- | --- | --- |
| 人物身份 / 人脸 | 脸型、五官结构、眼鼻嘴、下颌、发际线、比例与辨识度 | 表情、光照、湿发和妆容可随事件自然改变 |
| 多人物身份 + COS | 每个人独立的人脸与角色对应关系 | 禁止人脸互换、五官融合、同脸化和角色属性串位 |
| 构图 | 距离、高度、位置、透视、前中后景、人物面积、身体方向 | 不自动继承参考人物、身份、服装或背景 |
| 姿势 | 重心、肩胯、手臂与腿部趋势、旋转、头部和视线 | 转成动作未完成的自然瞬间，保持人体合理 |
| 摄影风格 | 曝光、反差、颗粒、色温、动态范围、高光、阴影、闪光、柔化、光晕 | 不自动复制具体人物和场景 |
| 发型 / 妆容 / 服装 / 配件 / 场景 | 用户指定的相应元素 | 与人物身份、角色和夏季环境协调 |

## Universal COS

支持电影、游戏、动漫、漫画、电视剧、小说、特摄、虚拟角色、虚拟偶像、原创 IP、OC、NPC、网络角色，以及同作品或跨作品多人 COS。

用户只给角色名时，识别发色、发型、刘海、瞳色、头饰、妆容、标志、主辅色、服装结构、饰品、手套、靴子、道具、图案、纹身、阵营符号和人格中最关键的辨识特征。遇到不熟悉或重名角色，使用可用的可靠资料确认，或询问作品名 / 角色设定；不要编造 OC 或混用不同版本。

- **Level 1｜Inspired**：轻度继承配色、发型与气质。
- **Level 2｜Recognizable Real-Life COS**：默认保留可辨识的造型、配件、视觉符号和人格，呈现现实成年 COSER。
- **Level 3｜Full COS**：强化原作妆容、头饰、服装结构语言和专属道具，仍适配真实夏季环境。

将角色的颜色、剪裁、几何结构、图形和材质语言、配件与标志转译成真实可穿的 Bikini、连体、运动或度假泳装。保留角色 DNA，不止是普通泳装换色。多人分别设计轮廓、领口、肩带、剪裁和符号，同时保持群体协调。

人格通过动作体现：冷酷型克制，元气型泼水大笑，成熟型松弛戏谑，傲娇型挡镜头或回头。避免所有角色成为同一种表情和气质。默认角色 COS 不改变现实背景；只有用户明确要求，才开启 Character Universe Environment Mode，仍保持连续空间和真实摄影语言。

## 自然抓拍与摄影

摄影者是熟悉的伴侣、朋友或同行者。人物可以向摄影者伸手、递饮料、挡镜头、泼水、回头等待或边说话边靠近。摄影者的手或前臂可少量入画作为 POV 线索，不抢主体。

多人采用不对称近中远层次，允许自然遮挡、局部裁切或轻微失焦；避免横排展示、等距站立、全员正面和同时看镜头。动作是 mid-action / transitional / unfinished gesture。

选择一种主要媒介：35mm 胶片、90s 便携胶片、2000s CCD、一次性相机或早期手机。核心焦段 28–40mm，按空间选机位。加入少量运动模糊、镜头水珠、柔边、光晕或曝光不完美，不以错误人体结构模拟摄影瑕疵。

毛孔、细汗毛、肤色差异、自然泛红、水珠、皮脂反光和湿布应可信。湿发程度、肌肉张力、重力、关节、布料贴合和运动方向符合事件。场景至少有一种水元素，可搭配少量浴巾、湿拖鞋、冰饮或沙滩包。

## 生成前检查

- 全部相关人物成年；身份、角色 DNA、人格和独立泳装正确，无人脸或角色元素串位。
- 所有人在同一空间、同一连续瞬间，围绕一个核心事件互动。
- 皮肤、布料、头发、肢体与动作真实，具有熟悉的 POV 和自然夏季抓拍感。
- 一种主要摄影媒介，机位合理，有水元素与少量生活痕迹。
- **ONE IMAGE / ONE FRAME / ONE SCENE / ONE CONTINUOUS MOMENT**。
- 禁止 collage、contact sheet、photo grid、split screen、storyboard、comic panels、multi-panel、diptych、triptych、film strip、Polaroid collage、moodboard、magazine layout、character sheet、character lineup sheet、照片墙、嵌套照片或多照片合一。
- 默认无 Logo、日期、时间、编号、REC、Battery、Focus box、Camera menu、Viewfinder UI、字幕、水印。胶片、CCD、DV 只描述成像质感。
- 避免商业泳装广告、棚拍、僵硬摆姿、塑料或 CGI 皮肤、过度磨皮、身份融合、重复人物和错误肢体。

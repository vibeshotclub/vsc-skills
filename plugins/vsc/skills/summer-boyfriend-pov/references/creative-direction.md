# 01｜绝对单图规则｜最高优先级

本 Skill：

**一次调用只生成一张图片。**

最终必须是：

**Single standalone photograph.**

**One image only.**

**One frame only.**

**One scene only.**

**One continuous moment only.**

这里的：

**Single Image**

只表示单幅画面。

并不表示只能出现一个人物。

一张图片内部完全允许：

- 一个人
- 两个人
- 三个人
- 多个人

前提是所有人物真实存在于：

**同一个空间、同一个时间点、同一个连续事件中。**

# 04｜多人不等于多图

这是核心规则。

多人模式依然必须是：

**ONE IMAGE**

**ONE FRAME**

**ONE SCENE**

**ONE MOMENT**

例如：

三位角色一起在泳池玩水：

正确：

**三个人同时存在于同一张真实抓拍照片中。**

错误：

将三个人分别放在三个小窗口里。

因此：

**Multi-person is allowed.**

**Multi-image composition is forbidden.**

# 25｜多人动作系统

多人场景优先：

**Interaction-based action。**

例如：

- A 向 B 泼水
- B 正在躲
- C 在旁边笑
- 两个人抢浴巾
- 一个人拉另一个下水
- 两个人同时跑出海浪
- 一人帮另一人整理头发
- 一个人递饮料
- 几个人坐池边聊天
- 一人挡镜头，另一人在后面笑

多人必须像：

**真正认识的人正在一起做一件事情。**

不是：

**几位模特各自摆 Pose。**

---

# 26｜单一事件原则

一张照片只围绕：

**一个核心事件。**

即使有多人：

所有人的动作也应围绕同一个事件形成自然反应链。

例如：

A 泼水。

B 躲水。

C 笑。

这是：

**一个事件。**

不要：

A 喝饮料
B 跑步
C 擦防晒
D 自拍

同时毫无关系地发生。

---

# 34｜多人构图

多人不要：

- 横排站立
- 全员正面
- 全员等距
- 全员同样大小
- 全员同时看镜头
- 偶像组合宣传照

优先：

**Asymmetric group composition。**

允许：

- 一人近景

# 45｜最终硬规则

### RULE 01

人物必须明确成年。

### RULE 02

一次只生成：

**一张独立图片。**

### RULE 03

单图不等于单人。

**多人完全允许。**

### RULE 04

所有人物必须处于：

**同一个真实场景、同一个连续瞬间。**

### RULE 05

支持人物垫图、多人物垫图以及任意电影、游戏、动漫、漫画等角色 COS。

**Character DNA + Character Personality。**

人物之间优先真实互动，不做角色横排展示。

### RULE 08

**自然抓拍，而不是商业泳装或 COS 宣传摄影。**

### RULE 09

绝不生成：

**拼图、联系表、分镜、多窗口、多画面、多照片合一。**

### RULE 10

整个 Skill 每次执行最终只产生：

**ONE STANDALONE PHOTOGRAPH。**

# 角色抓拍摄影

将角色名转译成成年真人 COS 或二次元角色摄影提示词，使用门框遮挡、玻璃反射、手机快拍和长焦空间压缩，营造虚构摆拍中的隐蔽观察感。原稿题名为《色狼视角角色摄影 Skill 提示词》，完整创作资料保存在 references/photography-guide.md。

与 vibeshot-candid-photography 的区别：本 Skill 以指定角色及其识别特征为核心，默认一组，支持 n=10；不使用固定韩国 INS 人像主体。

## 安装

在仓库根目录运行：

```bash
mkdir -p ~/.codex/skills
cp -R character-candid-photography ~/.codex/skills/
```

自定义 CODEX_HOME 时，改为该目录下的 skills。无需脚本、API 或外部依赖；本 Skill 默认只生成提示词。

## 输入示例

```text
使用 $character-candid-photography，成年原创猫耳侦探，深蓝短发、米色风衣、银色猫爪胸针，便利店，手机抓拍，n=1。
```

## 输出示例

明确成年的演员 COS 原创猫耳侦探，深蓝短发、米色风衣与银色猫爪胸针保持清晰辨识，站在便利店饮料柜前伸手挑选瓶装饮料。镜头从货架边缘观察，虚化包装盒遮挡左侧约四分之一画面；28mm 等效手机镜头，腰部高度环境抓拍，人物偏右，画面略倾斜，保留自然透视。冰柜冷白光混合店内照明，真实织物纹理、轻微数码噪点和手部运动模糊，面部仍清晰可辨。完整穿着，成年演员知情同意的虚构电影化摆拍，只有偶然抓拍的视觉效果。

## 批量示例

```text
使用 $character-candid-photography，成年原创猫耳侦探，n=10，日系街拍。
```

输出十组独立提示词，变化机位、焦段、前景、动作与光线，其中二至三组可表演发现镜头的瞬间。用户指定的地点、服装、数量等优先于默认选择。
